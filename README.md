## 📖 创客理念
作为一名计算机专业的大学生，我理解的创客并非单纯的“动手爱好者”，而是以创新为核心、以实践为路径的创造者。创客精神在于不满足于现有知识的吸收，更强调将想法落地——从脑海中的创意，到用代码、工具、材料将其转化为具体的实物或应用。

在大学阶段，创客思维让我们跳出课本的框架，把课堂学到的编程、建模、焊接等技能融合起来，解决真实的小问题，比如设计校庆文创、制作智能小装置。创客也不是孤军奋战，而是乐于分享、协作，在尝试与试错中积累经验，哪怕是一次失败的3D打印、一段调试不通的代码，都是创客成长的一部分。这种“敢想敢造、知行合一”的态度，正是大学生创客最珍贵的特质。

## 🚀 创客创新项目
### 中期创客项目——基于开源3D打印的WiFi控制六轴机械臂
- 团队成员：刘宸宇（编程/调试）、束伟（3D打印/组装）
- 项目背景：设计并实现一款基于ESP32的WiFi控制六轴机械臂，通过3D打印获取结构件，搭配舵机实现六轴运动，提供网页端可视化控制界面。
- 核心步骤：开源项目检索与模型下载 → 3D打印所有结构件 → 嵌入式程序编写（舵机驱动、WiFi联网、网页界面） → 机械臂组装与接线 → 程序烧录与联调测试。
- 遇到的问题及解决：
  - 打印件尺寸偏差 → Bambu Studio微调缩放比例（+0.5%）重新打印；
  - 舵机角度抖动 → 优化servoMove函数，增加constrain限制，调整脉冲宽度（500-2400μs）；
  - WiFi连接不稳定 → 优化重连逻辑，缩短handleClient轮询间隔。
- 成果：通过浏览器访问ESP32的IP地址即可实时控制机械臂各关节（底座、大臂、小臂、手腕俯仰/旋转、夹爪），支持滑块调节、一键复位、抓取/松开，控制响应延迟＜200ms。
- 详情见：[中期创客项目](midterm-project.html)

### 期末创新项目——舵机驱动空气质量检测遥控小车
- 团队成员：刘宸宇（嵌入式固件开发、ESP-NOW通信协议、传感器驱动、FreeRTOS架构、TFT UI、舵机控制、全流程调试）、束伟（3D建模与打印、机械装配）
- 项目背景：设计并实现一款基于ESP32-C3的ESP-NOW遥控小车，集成空气质量检测、超声波避障、GPS定位等功能，遥控器端配备TFT屏幕四页面实时显示传感器数据。
- 核心步骤：ESP-NOW通信裸板验证 → 舵机驱动调试（LEDC弃用，换ESP32Servo库） → TFT屏幕调通（7种组合尝试） → FreeRTOS实时任务架构 → 传感器集成（HC-SR04中断测距、MQ-135空气质量、GPS定位） → 四页面UI系统重构 → 实车联调与参数优化。
- 遇到的8个关键Bug及解决：
  - ESP-NOW信道漂移致收包率崩溃（~1 pkt/s） → 强制锁定信道1，跃升至220+ pkt/s；
  - LEDC PWM不产出波形（Arduino Core 3.3.8兼容问题） → 更换ESP32Servo库；
  - 前进慢/后退正常（三因叠加：loop阻塞+竞态条件+HC-SR04噪声） → FreeRTOS独立舵机任务+统一限速入口+中断+脉宽校验+中值滤波；
  - TFT彩边偏移（7次失败） → 最终确认INITR_GREENTAB + rotation 0；
  - GPIO9(Flash CS)占用致启动崩溃 → 迁移到GPIO10；
  - GPIO19(USB D+)占用致SW2无响应 → 迁移到GPIO10；
  - U8g2与ST7735底层冲突 → 放弃中文，全英文6×8px字体；
  - GPS引脚反接 → 交换HardwareSerial::begin()的RX/TX参数。
- 成果：遥控器四页面（驾驶/测距/GPS/空气质量）实时切换，摇杆始终控制小车，50cm预警减速+30cm刹停避障，全系统同源供电稳定运行。
- 详情见：[期末创新项目](final-project.html)
